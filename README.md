# College Database Management System

## Project Overview
The College Database Management System is a DBMS mini project developed using Oracle SQL. It manages college-related information such as students, departments, faculty members, courses and student enrollments.

## Objectives
- Store student and faculty information.
- Maintain department and course details.
- Manage student enrollment records.
- Establish relationships using primary and foreign keys.
- Apply database normalization to reduce data redundancy.

## Technologies Used
- Oracle SQL
- Oracle SQL Developer
- GitHub

## How to Run
1. Open Oracle SQL Developer.
2. Connect to your Oracle database.
3. Execute `01_Create_Tables.sql`.
4. Execute `02_Insert_Data.sql`.
5. Execute the verification and query files.
